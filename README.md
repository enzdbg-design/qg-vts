# QG VTS Rallye Passion

Le Quartier Général animé des agents IA de VTS Rallye Passion : un open space en pixel art où 32 agents, répartis en 9 pôles, travaillent en direct.

- `index.html` : la page complète (moteur pixel art, agents, fiches, barre d'outils).
- Polices : Anton, Bebas Neue, Montserrat, Silkscreen (licence SIL Open Font).
- Hébergement : Vercel, site statique, sans étape de build.

Mode nuit : ajouter `#nuit` à l'adresse, ou cliquer sur ☾.
